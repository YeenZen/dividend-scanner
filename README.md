# dividend-scanner

แจ้งเตือนทางอีเมลเมื่อหุ้นปันผลไทยในลิสต์ราคาตกจนใกล้ได้ yield 10%

รันอัตโนมัติด้วย GitHub Actions ทุกเช้า **07:00 น. เวลาไทย จันทร์–ศุกร์**
ไม่ต้องเปิดคอมทิ้งไว้

## ส่งอีเมลเมื่อไหร่

| สถานะ | เงื่อนไข |
|---|---|
| 🟢 | yield ตั้งแต่ 10% — ถึงเป้าแล้ว |
| 🟡 | yield 8–9.99% — ใกล้ถึง |
| ⚪ | yield ต่ำกว่า 8% — ไม่เข้าอีเมล |

**ส่งเฉพาะวันที่มีอย่างน้อย 1 ตัวเป็น 🟢 หรือ 🟡** วันไหนไม่มีก็ไม่ส่ง กันจดหมายขยะ
ยกเว้นกรณีดึงข้อมูลพังเกินครึ่งลิสต์ จะส่งอีเมลแจ้งว่าระบบมีปัญหา —
จงใจให้ดังไว้ เพราะถ้าพังเงียบ ๆ จะแยกไม่ออกจาก "วันนี้ไม่มีหุ้นถึงเป้า"

ผลแต่ละวันเก็บไว้ที่ `scans/YYYY-MM-DD.md` ดูย้อนหลังได้

## ตั้งค่า (ทำครั้งเดียว)

ต้องใส่ 3 secret ที่ **Settings → Secrets and variables → Actions → New repository secret**

| ชื่อ | ค่า |
|---|---|
| `GMAIL_USER` | อีเมล Gmail ที่ใช้ส่ง |
| `GMAIL_APP_PASSWORD` | App Password 16 ตัว (ไม่ใช่รหัสผ่าน Gmail ปกติ) |
| `ALERT_TO` | อีเมลปลายทาง (ไม่ใส่ก็ส่งเข้าตัวเอง) |

วิธีสร้าง App Password: ต้องเปิด 2-Step Verification ของบัญชี Google ก่อน
แล้วไปที่ [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
ตั้งชื่อว่า `dividend-scanner` จะได้รหัส 16 ตัวมาใส่ใน `GMAIL_APP_PASSWORD`

> repo นี้เป็น public — อีเมลกับรหัสผ่านจึงเก็บใน secret ทั้งหมด ไม่ฮาร์ดโค้ดในไฟล์

## ทดสอบ

- กดรันเองได้ที่แท็บ **Actions → แจ้งเตือนหุ้นปันผลรายวัน → Run workflow**
- รันในเครื่องโดยไม่ส่งอีเมล: `python alert.py --dry-run`

## ที่มาของข้อมูล

ดึงจาก `settrade.com/th/equities/quote/{TICKER}/overview`

ไม่ใช้ `set.or.th/api` เพราะอยู่หลัง Imperva ยิงด้วย urllib/curl ได้ 403 เสมอ ต้องเปิด browser จริง
ส่วนหน้า quote ของ Settrade เป็น Nuxt SSR ที่ฝังข้อมูลมาใน HTML เลย จึงดึงได้ด้วย stdlib ล้วน
ไม่ต้องลง dependency อะไรเลย

**ราคาเป้า yield 10% = ราคาล่าสุด × yield ปัจจุบัน ÷ 10**

สูตรนี้ไม่ต้องพึ่ง DPS จึงอัพเดตตัวเองเมื่อบริษัทเปลี่ยนปันผล ไม่ต้องมาแก้ตารางราคาเป้าด้วยมือทุกปี
(ค่า `dividend` ที่เว็บให้มาเชื่อไม่ได้ — บางตัวเป็นแค่งวดเดียวไม่ใช่ทั้งปี)

## ลิสต์หุ้น

33 ตัวใน `WATCHLIST` ที่ [alert.py](alert.py) ทุกตัวตรวจแบบฟอร์ม 56-1 ย้อนหลัง 5 ปีแล้ว
ผ่านเกณฑ์ payout ratio ต่ำกว่า 80% และมี moat ที่ยืนยันด้วยตัวเลขส่วนแบ่งตลาดจากแหล่งอิสระ

เพิ่ม/ลดหุ้นได้โดยแก้ `WATCHLIST` ตรง ๆ — เป็น list ของ `(ticker, หมายเหตุ)`

⚠️ **ระบบนี้บอกแค่ว่าราคาถึงเป้าเมื่อไหร่ ไม่ใช่คำแนะนำให้ซื้อ**
yield สูงอาจมาจากปันผลพิเศษครั้งเดียว หรือราคาร่วงเพราะข่าวร้าย — เช็คสาเหตุก่อนซื้อทุกครั้ง
